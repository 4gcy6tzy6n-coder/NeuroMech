# Summaries and lessons learned

The directory name `summery/` follows the repository owner's requested spelling. Add one subdirectory per experimental round. Each round summary should record:

- question and scope;
- biological evidence and its limits;
- model/benchmark version and result location;
- positive findings;
- failures, corrections, and deviations;
- whether the run is exploratory or confirmatory;
- what the result does and does not establish.

Do not erase failed or superseded runs; retain them as provenance.
