## M2_CROSS_TASK_STATE_FEEDBACK_V1 — 人工迁移边界测试

**实验结果：** 在合成的标量潜在状态估计任务中，模式条件化增益滤波器相对四参数通用标量 RNN 的主对比为 `MSE(RNN) − MSE(模式增益)`。训练关系保持时差值为 `+0.1040`，交叉 bootstrap 95% 区间 `[+0.0932, +0.1157]`，20/20 个训练种子的均值为正。上下文与传感器可靠性独立时，模式滤波器的 MSE 高于无上下文恒定增益滤波器；关系反转时，主对比反向为 `−0.0352`，通用 RNN 优于模式滤波器。

**分析：** 结果支持一个有限的人工算法结论：当状态上下文确实预测观测可靠性时，显式条件化的感觉更新可以改善这一特定合成任务；映射反转时该规则会成为负担。蠕虫生物证据支持运动状态反馈调制感觉处理，但没有证明运动状态编码传感器可靠性，也没有证明动物实现了这个滤波方程。因此这不是生物机制验证，也不能外推为广泛 AI 优势。独立复核通过；本实验在项目层面属于探索性、结果知情工作。

**失败经验与限制：** 通用 RNN 只是一个窄基线；解析 Kalman 基线掌握任务模型、且不是容量匹配对照；本实验仅覆盖一个合成任务族。可靠性映射依赖条件变化，不能把对齐条件的优势视为无条件迁移。

**状态：** 人工迁移测试完成；不构成生物验证或 publication-ready 结论。GitHub 实验提交见项目 README 中的独立实验记录。
