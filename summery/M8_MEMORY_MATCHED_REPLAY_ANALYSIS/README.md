# M8 memory-matched replay analysis

This folder records the post-result comparison of exact replay and the delay-matched truncated-history arm. The analysis contract, result, and limitations are in `ANALYSIS_STATUS.md`, `RESULTS.md`, and `STRENGTHS_AND_FAILURES.md`.

The analysis reuses the M8 synthetic task outcomes and seeds. It does not directly test the M5 eligibility-trace update rule, establish biological validation, or support a general replay-versus-trace claim. Reproduction instructions and archived inputs are linked from the repository README and `data/results/M8_MEMORY_MATCHED_REPLAY_ANALYSIS/`.
