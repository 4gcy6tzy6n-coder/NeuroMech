# Limitations and failure record

- **Missing independent-unit linkage:** run events cannot be grouped back to worms from the released Figure 6C table. This blocks new animal-level confidence intervals or significance tests. Event rows were not substituted for animals.
- **Unequal event counts:** the sheet has 1,008 WT events and 3,910 RIM-ablated events. Pooled summaries are run-weighted, and animals contributing more events receive more weight.
- **Post-result descriptive choices:** the six/twelve direction bins and 30 s tail summary are exploratory. They are not preregistered or confirmatory.
- **Scope:** this is a source-data reanalysis, not a new biological manipulation, mechanistic identification of a synaptic carrier, or AI-transfer result.
