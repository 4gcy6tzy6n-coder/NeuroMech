# M2 low-data conditional-update benchmark V2 — failure and interpretation log

V2 strengthens V1's additive comparator by adding a four-parameter bilinear tanh recurrence with an explicit `y*q` term. The mode-gain filter still scored lower error on the synthetic task, but it also won under independent and reversed context mappings. This outcome fails to isolate an alignment-specific contextual computation: the relative advantage may arise from the state-update form or optimization properties rather than from using the biologically motivated state relation.

The reversed-condition mode-gain MSE was about 0.096 versus 0.056 when aligned. A better relative score than the bilinear model under reversal is therefore not evidence that the learned policy adapted to the changed mapping. The generic comparator also retained a tanh state nonlinearity while the mode-gain update is an affine prediction-error filter with sigmoid-constrained gains. Equal parameter count and sample tokens do not remove that functional-form difference; the generic model also took longer in this CPU execution.

V1 and V2 differ in comparator family and use disjoint seeds. V1's additive RNN was better under mismatch; V2's bilinear tanh RNN was worse in every mapping. This sensitivity to comparator choice is a warning against claiming a robust M2 transfer effect from the current synthetic family. The next comparison should include a linear bilinear state update, a context-free state-space/filter baseline, a zero-estimate sanity reference, and a task-aware Kalman reference, with learning procedures calibrated independently of evaluation outcomes. Any positive claim should survive those controls and an independently designed task family.
