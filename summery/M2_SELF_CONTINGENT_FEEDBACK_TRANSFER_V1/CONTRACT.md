# M2_SELF_CONTINGENT_FEEDBACK_TRANSFER_V1

**Classification:** exploratory artificial mechanism-transfer experiment. Earlier biological and M2 artificial results are known. This does not constitute a biological reanalysis, confirmatory project-level study, or general AI result.

## Biological and computational motivation

Ji et al. report that RIM-dependent motor-circuit feedback affects AIY representation and sustained forward behavior in a *C. elegans* thermotaxis circuit (eLife 10:e68848, DOI `10.7554/eLife.68848`). Separately, the project's source-model counterfactual preserved the population feedback distribution while permuting which simulated agent received each feedback trajectory. That is model evidence, not an independent biological experiment. Together they motivate a narrow computational question: does motor-state feedback help an artificial controller because the signal tracks that controller's own evolving state, beyond receiving a marginally identical signal from another trajectory?

The experiment operationalizes **self-contingency** as sensory-site input from the same trajectory's current plant state. The yoked control receives a fixed derangement of contemporaneous feedback signals generated by the trained self-feedback controller on the same exogenous evaluation batch. At every time step, the population distribution is therefore exactly preserved while recipient-specific correspondence is broken. This is an artificial translation; it does not assert that the worm uses this exact equation or that the project source-model result is biological causal evidence.

## Question and frozen hypothesis

In a tracking controller exposed to transient contradictory sensor pulses, does self-contingent motor feedback at the sensory-state update reduce held-out motor-state MSE relative to a cross-agent-yoked sensory input whose instantaneous population distribution is exactly matched?

**Primary endpoint:** held-out mean motor-state squared error in `SLOW_TRANSIENT` (`target switch hazard = 0.01`, sensor-pulse onset rate `0.08`, pulse duration 2 steps).

**Primary contrast:** `CROSS_AGENT_YOKED_SENSORY − SELF_SENSORY` across 32 paired training seed blocks. Positive values favor self-contingent feedback. This is the only confirmatory-within-this-run contrast; all project-level conclusions remain exploratory.

## Task generator

Each test sample is a population of 128 independent 1D tracking trajectories, evaluated in parallel for exact population-level feedback-distribution matching. Target state is binary (`−1/+1`) and switches with condition-specific hazard. Sensors normally report the target with Gaussian SD `0.25`; during a two-step pulse, the sensor polarity is contradicted. A first-order motor plant follows `m[t] = 0.70*m[t−1] + 0.30*u[t−1] + ε[t]`, with motor-noise SD `0.03`. Controllers observe the current sensor value and, according to arm, their own motor state or yoked feedback. Training uses hazard `0.02` and pulse onset rate `0.03`.

Test conditions are:

| Condition | Target-switch hazard | Sensor-pulse onset rate | Pulse duration |
|---|---:|---:|---:|
| `SLOW_TRANSIENT` (primary) | 0.01 | 0.08 | 2 steps |
| `FAST_TRANSIENT` | 0.05 | 0.08 | 2 steps |
| `SLOW_CLEAN` | 0.01 | 0.00 | none |
| `FAST_CLEAN` | 0.05 | 0.00 | none |

The slow/fast comparison probes the expected boundary: self-generated motor state may be a useful short-term prior when targets persist and transient sensor conflicts occur, while becoming stale more quickly under rapid target switches.

## Controller arms

| Arm | Feedback route | Parameters |
|---|---|---:|
| `SELF_SENSORY` | Own motor-state signal enters sensory-state update | 4 |
| `CROSS_AGENT_YOKED_SENSORY` | Same-size sensory-state model receives deranged donor motor-state signals | 4 |
| `SELF_OUTPUT` | Own motor-state signal enters output command | 4 |
| `NO_FEEDBACK` | No motor-state feedback | 3 |
| `GENERIC_RNN_1D` | Additive action-conditioned scalar recurrent controller | 6 |
| `GRU_8` | Eight-unit action-conditioned GRU | 297 |

The self/yoked sensory pair has identical equations, parameter count, optimizer updates, training streams, and test sensor/target streams. Their only intended distinction is whether the feedback trajectory is recipient-contingent. The output-site arm is a parameter-matched placement control. The generic RNN and GRU are stronger but larger references; their equal update count is not equal compute.

## Training, test split, and analysis

- Training seed blocks: `810000–810031` (32 blocks).
- For each seed and update, every arm uses identical generated training episodes. Each learned arm uses 100 Adam updates, batch size 32 trajectories, horizon 96, learning rate 0.01, and gradient clipping 5.
- The `SELF_SENSORY` policy is fitted first within each seed. Its motor-state signal is then recorded on the same training trajectories and permuted across trajectory IDs to supply the yoke model during training. No test data or test outcomes are used in fitting.
- Test trajectories use distinct deterministic seed ranges, 128 paired-independent trajectories per seed block and condition. All arms share the target, sensor-noise, pulse, and motor-noise realizations. The yoke derangement is fixed per seed/condition and has no fixed points.
- Primary uncertainty unit is the training seed block (`n=32`); trajectories and time steps are not treated as independent replicates. The primary interval is a 20,000-resample percentile bootstrap over seed-block paired differences (seed `8,765,432`).
- Secondary metrics: movement MAE, sign accuracy, command energy, switch count, and switch-recovery latency. Report them by condition without confirmatory language or cross-condition pooling.

## Validity checks and interpretation boundary

The verifier must establish unique row coverage, expected arm/condition/episode counts, correct parameter counts, correct yoke derangements, exact equality of sorted self and yoked feedback values at every time step, primary contrast recomputation, and artifact hashes. An independent full rerun must reproduce test episode metrics, seed summaries, and primary summary byte-for-byte; fit timing may differ.

A positive primary contrast would support only the utility of recipient-contingent feedback in this binary tracking simulator under the frozen slow-transient condition. It would not establish biological self-contingency, new worm causality, general robustness, or broad AI benefit. A null or reversed result would narrow this artificial translation and would not refute the biological evidence. The project-level M1/M2 claim remains conjunctive and cannot be inferred from this experiment alone.
