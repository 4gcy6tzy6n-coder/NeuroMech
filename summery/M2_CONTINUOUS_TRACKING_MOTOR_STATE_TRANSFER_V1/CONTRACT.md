# M2 continuous tracking motor-state transfer V1

**Classification:** exploratory, post-result artificial transfer experiment. It follows prior M2 sensory-feedback and GRU motor-input studies. It changes task family and tests an abstraction motivated by experimentally reported motor-state representation in the C. elegans RIM–AIY system. It is not biological validation.

## Biological computation and artificial question

Ji et al. (eLife 2021, DOI `10.7554/eLife.68848`) report that AIY activity carries locomotor-state and thermosensory information, with the locomotor component requiring RIM. The bounded abstraction tested here is that an internal sensory estimate can benefit from feedback about the organism/controller's realized motor state. This does not imply the biological circuit computes a GRU or that worm forward/reversal state is equivalent to a two-dimensional actuator velocity.

Question: in continuous 2D target tracking with actuator inertia/noise and bursty observation loss, does providing the realized motor state to a strong recurrent controller improve held-out tracking beyond (a) the same controller with no motor-state input, (b) its own previous action command, and (c) a population-distribution-matched motor-state yoke from another episode?

## New task family

Each episode has a continuously moving target with autoregressive velocity and a controlled persistence parameter. The agent observes noisy target-relative position when the sensor is available. The sensor can enter Markov bursts of missing observations. The agent's actuator has inertia and independent motor noise; actual velocity can therefore differ from the previous command. The controller emits a two-dimensional command and is trained end-to-end to minimize target-relative squared distance plus a small fixed command-energy penalty.

Training uses 32 fresh paired training-seed blocks (`850000–850031`), 32 trajectories per update, 64 steps, and 100 Adam updates. Each batch samples target-velocity persistence uniformly from `[0.84,0.97]`; observation availability has 50% missingness with mean missing-burst length 4. Evaluation uses four held-out profiles: train-like persistence/dropout, long missing bursts, lower missingness, and faster target dynamics. Within each block × profile, all arms receive the same target path, sensor-noise, availability, and motor-noise realizations.

## Model arms and resource accounting

All arms use the same `GRUCell(5,8)` plus two-output linear readout, **378 trainable parameters**, same initial parameter values within each block, 100 Adam updates, and identical training examples and optimizer schedule. Five inputs are noisy relative x/y (or zero during dropout), an observation-available flag, and feedback x/y:

- `GRU_SELF_MOTOR`: actual current actuator velocity.
- `GRU_ZERO_MOTOR`: both feedback coordinates are zero; the input channel and parameters remain present.
- `GRU_ACTION_COPY`: previous command, testing whether intended action suffices without realized motor state.
- `GRU_YOKED_MOTOR`: another episode's actual motor-state sequence through a per-batch derangement with no fixed points. Training donors are generated by the fitted self-motor model on the same exogenous batch; test donors are generated on the same held-out batch. This preserves the exact instantaneous population distribution at each step while breaking episode identity.

## Primary estimand and uncertainty

Primary condition: `LONG_MISSING_BURSTS`. Primary metric: episode-mean squared target-relative distance, averaged first within each training seed block and then across blocks. Primary paired contrast: `GRU_SELF_MOTOR − GRU_ACTION_COPY`; negative favors realized motor-state feedback over the controller's own previous command. Secondary paired contrasts are self motor versus zero input and yoke. Bootstrap the 32 training-seed blocks (20,000 draws; seed 8,765,501). Episode and time-step rows are not independent inferential units. Other conditions and metrics remain descriptive.

## Interpretation

A primary advantage would support a task-conditional contribution from realized actuator-state input in this new artificial task family, beyond an equal-capacity recurrent controller receiving its own command. It would not establish a biological-to-AI transfer effect, general AI benefit, or equivalence to a specific synapse. A null or adverse result would bound the tested abstraction under these dynamics. The task is still synthetic and the study is exploratory because prior M2 outcomes motivated the test.
