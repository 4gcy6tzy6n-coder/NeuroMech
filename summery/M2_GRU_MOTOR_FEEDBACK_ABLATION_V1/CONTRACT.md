# M2 GRU motor-feedback ablation V1

**Classification:** post-result exploratory mechanism-attribution experiment. It follows several M2 artificial transfer runs, including a result where GRU-8 outperformed all low-dimensional controllers. It is not independent task generalization or biological validation.

## Question

Does the motor-state feedback input add held-out value to a high-capacity recurrent controller in the existing target-tracking/transient-conflict task, beyond what the same recurrent architecture can do with sensory input and internal memory alone? Does preserving the population signal distribution while breaking recipient identity retain that value?

## Task and arms

Reuse the M2 binary target-tracking task generator, four evaluation conditions, motor plant, training/evaluation lengths, optimizer, and primary SLOW_TRANSIENT condition from `M2_FEEDBACK_TEMPORAL_ALIGNMENT_V1`. Use 32 fresh paired training-seed blocks `840000–840031`; within a block all arms receive identical training and held-out exogenous target, observation-noise, and motor-noise streams.

All arms use an identical `GRUCell(2, 8)` plus scalar readout (297 trainable parameters), the same initial weights within each seed block, 100 Adam updates, batch size 32, and 96-step sequences:

- `GRU_SELF_MOTOR`: current own motor-state signal is the second GRU input.
- `GRU_ZERO_MOTOR`: the same second input channel is fixed to zero during training and evaluation; architecture and parameter count remain unchanged.
- `GRU_YOKED_MOTOR`: the second input receives another episode's motor-state signal, through a fresh derangement with no fixed points. Training donor signals come from the fitted `GRU_SELF_MOTOR` on the same exogenous batch; test donor signals are generated by the fitted self-feedback model on the same held-out exogenous batch. The instantaneous population distribution is therefore preserved exactly while recipient identity is broken.

The motor signal is `sigmoid(5 × motor_state)`, as in the previous M2 controller implementation. The zero-input and yoked arms are not described as biological perturbations; they are artificial input ablations.

## Outcomes and inference

Primary metric is held-out movement MSE in SLOW_TRANSIENT. The primary paired contrast is `GRU_SELF_MOTOR − GRU_ZERO_MOTOR` over the 32 training-seed blocks; negative values favor the motor-feedback input. A secondary paired contrast compares self-motor with yoked-motor input. Bootstrap seed blocks (20,000 draws; seed 8,765,440). Episode-level samples are not independent inferential units.

Secondary condition and metric summaries are descriptive. Do not select conditions, horizons, or metrics after inspecting results. Report parameter counts and keep the strong model's results distinct from the low-dimensional mechanistic controller.

## Interpretation limits

A primary benefit would show that this controller uses motor-state input under this task and training procedure. It would not show that the worm circuit implements the GRU, establish a biological causal effect, or demonstrate a general AI advantage. A null or adverse result would show that the GRU's previous performance did not require this explicit motor-state channel in the tested implementation. The task is reused from the earlier M2 family, so this study is mechanistic attribution, not a claim of independent generalization.
