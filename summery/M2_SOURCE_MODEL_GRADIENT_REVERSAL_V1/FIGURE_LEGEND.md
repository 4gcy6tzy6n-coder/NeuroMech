# Figure legend — gradient-reversal stress test

**Sensory-site feedback supports model progress under gradient reversals, but the output-site control saturates.** (a) Paired changes in environment-aligned progress rate for the sensory-site feedback arm relative to no feedback (solid teal) and the nominal output-site feedback control (dashed rose) across stationary and reversing-gradient simulations. The 20-second interval was the frozen primary condition; the sensory-minus-output contrast is not interpretable as a site-specific effect because the output-site arm saturated. (b) Forward-state occupancy shows the control failure: the output-site arm remained in the forward state throughout the 200-second simulation. Points show means across 100 simulated seed blocks; error bars are 95% percentile bootstrap intervals over seed blocks (20,000 resamples). Panel a uses within-seed paired differences; panel b resamples the seed-block means for each arm. Each block contains 50 simulated agents, which are not treated as independent replicates. These are outputs of a translated source model, not biological observations or evidence of AI-transfer benefit.
