# M5 eligibility trace memory frontier V1 — runtime and analysis limits

1. **Python 3.9 / Accelerate warnings.** The first full run under Python 3.9.6 / NumPy 2.0.2 emitted divide-by-zero, overflow, and invalid-operation warnings at matrix multiplication sites. All saved accuracy values were finite and in `[0,1]`, but this run is retained only as a diagnostic. The full fresh-seed run under Python 3.12.13 / NumPy 2.4.4 emitted no warnings; its 2,430 row-level task metrics were byte-identical to the diagnostic run. Use the Python 3.12 result as canonical.
2. **Delayed-replay state accounting.** Exact replay uses a FIFO of prior feature vectors capped at the delay length; the current input is transient and excluded. Horizon arms retain at most H feature vectors and age them to label arrival. Eligibility retains one 64-value vector. All counts exclude shared model weights and prediction-history storage; do not describe them as measured process memory.
3. **Interpretation boundary.** The task family and parameters were selected after earlier M5/M8 outcomes. Seeds 30–59 are new, but the experiment remains exploratory. The pooled trace advantage does not hold in every rho × delay cell, and exact replay is much more accurate in all cells. Do not generalize beyond this fixed synthetic generator or present the result as biological validation.
