# M5 delayed-reward contextual-bandit result files

This directory contains the fixed run's task-level held-out expected rewards, training trajectories, seed-by-delay contrasts, run manifest, and independent post-run verification. The experimental contract and interpretation are in `summery/M5_DELAYED_REWARD_BANDIT/`.

This is a post-result exploratory synthetic transfer test of a norm-matched eligibility update in a linear softmax contextual-bandit policy. It is not biological or connectome evidence. Task seed is the inference unit; individual decisions are not independent replicates. The exact-replay comparator outperformed the trace, and the trace advantage declined with delay.

Files are pinned by `SHA256SUMS.txt` in this directory.
