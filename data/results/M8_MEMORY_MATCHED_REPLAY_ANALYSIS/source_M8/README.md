The analysis reads this archived CSV and regenerates results in the sibling `output/` directory. The complete original M8 experiment package is not duplicated here; see the source references and limitations in `summery/M8_MEMORY_MATCHED_REPLAY_ANALYSIS/RESULTS.md`.
