# M2 feedback-site control result files

This directory contains development-seed calibration outcomes, held-out seed-block metrics, the arm comparison summary, a figure, and the run manifest. The frozen contract and interpretation are in `summery/M2_JI2021_FEEDBACK_SITE_CONTROL_V1/`.

The test outcomes use 100 new seed blocks with 50 agents clustered within each block. This is simulator uncertainty only. The held-out motor-only control did not exactly match the source model's mean forward-run duration, so the site comparison is not a fully persistence-matched causal contrast.

Files are pinned by `SHA256SUMS.txt`.
