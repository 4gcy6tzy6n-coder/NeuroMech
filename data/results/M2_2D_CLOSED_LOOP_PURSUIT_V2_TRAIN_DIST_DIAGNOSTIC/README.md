# Canonical results

This folder contains the canonical output from `M2_2D_CLOSED_LOOP_PURSUIT_V2_TRAIN_DIST_DIAGNOSTIC`.

- `canonical/episode_metrics.csv`: per-seed, per-regime, per-condition, per-policy outcomes.
- `canonical/training_metrics.csv`: fitted parameters, losses, and runtime by seed, training regime, and model.
- `canonical/summary.json`: machine-readable aggregate results and crossed-bootstrap intervals.
- `canonical/run_manifest.json`: run parameters, source hashes, and output checksums.

The results are post-result exploratory and do not replace V1. See the [contract and interpretation](../../../summery/M2_2D_CLOSED_LOOP_PURSUIT_V2_TRAIN_DIST_DIAGNOSTIC/).
