# Canonical results

This directory contains the canonical outputs for `M2_SOURCE_MODEL_GRADIENT_REVERSAL_V1`.

- `canonical/seed_block_metrics.csv`: paired simulation seed-block outcomes by feedback arm and gradient reversal interval.
- `canonical/summary.json`: arm means and paired bootstrap contrasts.
- `canonical/run_manifest.json`: source, contract, code, seed, environment, and output hashes.
- `canonical/Figure_M2_SOURCE_MODEL_GRADIENT_REVERSAL_V1.*`: editable figure exports and high-resolution raster.
- `canonical/figure_source_data.csv`: plotted paired contrasts and arm aggregates with interval definitions.
- `canonical/figure_manifest.json`: plot source/data/output provenance; the adjacent alignment and collision-audit JSON files record render QA.
- The experiment is a source-derived model stress test and does not support animal-level or AI-transfer claims.
