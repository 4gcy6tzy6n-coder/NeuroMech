# Preliminary run note

This directory preserves the initial 12-seed run before adding a constant-input recurrent-clock control. Its episode outcomes are finite, but that comparison could not distinguish biological-profile use from generic recurrent step counting. The final report and project README therefore use only the rerun in the parent directory, which includes profile-input and constant-input GRUs. The pilot is retained for provenance and must not be interpreted as the final comparison.
