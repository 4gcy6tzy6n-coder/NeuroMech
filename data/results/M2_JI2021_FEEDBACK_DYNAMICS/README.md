# M2_JI2021_FEEDBACK_DYNAMICS result files

This directory contains the 900 seed-block × feedback × noise-scale summaries, the paired-bootstrap summary, a feedback/noise plot, and the run manifest for the exploratory reimplementation of the Ji et al. Figure 7 thermotaxis model. The experiment definition and interpretation are in `summery/M2_JI2021_FEEDBACK_DYNAMICS/`.

The metrics describe model simulations, not worms. The simulation-seed block is the resampling unit; the 50 agents within each block share random-number streams and are clustered. The noise-scale conditions are synthetic stress tests.

Files are pinned by `SHA256SUMS.txt`.
