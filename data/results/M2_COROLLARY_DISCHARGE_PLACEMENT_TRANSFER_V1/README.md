# Canonical results

This directory stores the canonical output of `M2_COROLLARY_DISCHARGE_PLACEMENT_TRANSFER_V1`.

- `canonical/episode_metrics.csv`: per-seed, hazard, episode, and policy outcomes.
- `canonical/training_metrics.csv`: fitted parameters, losses, and runtime for trained models.
- `canonical/summary.json`: machine-readable means and primary/secondary contrasts.
- `canonical/run_manifest.json`: run parameters, source hashes, and output checksums.

The study is post-result and exploratory. See the [contract and limits](../../../summery/M2_COROLLARY_DISCHARGE_PLACEMENT_TRANSFER_V1/).
