# CROSS_MECHANISM_CONTEXT_MEMORY_V1

Reproduce from the repository root:

```bash
python3 model/CROSS_MECHANISM_CONTEXT_MEMORY_V1/run_experiment.py
python3 model/CROSS_MECHANISM_CONTEXT_MEMORY_V1/verify_results.py
```

The runner refuses to overwrite a nonempty output directory. Canonical outputs are in `data/results/CROSS_MECHANISM_CONTEXT_MEMORY_V1/canonical/`. M2 MSE and M5 accuracy remain separate; this experiment is exploratory and does not establish biological validation.
