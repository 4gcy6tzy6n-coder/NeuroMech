Run the fixed task grid from the repository root with `python3.12 model/M5_ELIGIBILITY_TRACE_MEMORY_FRONTIER_V1/run_experiment.py`. Recompute the paired seed-level primary estimate and verify row coverage and logical memory accounting with `python3.12 model/M5_ELIGIBILITY_TRACE_MEMORY_FRONTIER_V1/verify_results.py`. The runner writes to `data/results/M5_ELIGIBILITY_TRACE_MEMORY_FRONTIER_V1/canonical/` and refuses to overwrite a nonempty destination.

The task generator is synthetic and the task family was selected after prior results were known. This tests an artificial eligibility algorithm, not a biological synapse or a general AI claim.
